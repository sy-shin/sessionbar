# sessionbar 변경 기록 / Changelog

## 0.2.0-beta.1

### 한국어

- Apple Silicon·Intel용 Universal 앱을 DMG·ZIP으로 배포합니다.
- 미확인 목록에서 승인·입력 요청, 아직 읽지 않은 완료 결과, 확인하지 않은 오류를 관리합니다.
- 목록·상세 화면에서 작업 창으로 이동하고 선택한 Codex를 종료할 수 있습니다.
- 터미널 탭 없음·자동화 권한·응답 지연·창 조회 실패를 구분합니다. 탭을 찾지 못하면 확인된 출처 앱으로 이동합니다.
- macOS 알림 권한을 표시하고, 오래된 기록의 알림과 해결된 요청의 반복 알림을 억제합니다.
- 한국어·영어 사용 영상과 설치·업데이트 안내를 제공합니다.

### English

- Universal app for Apple Silicon and Intel Macs, packaged as DMG and ZIP.
- Review approval/input requests, unread completed results, and unreviewed errors.
- Return to task windows and quit the selected Codex from the list or detail view.
- Distinguish missing tabs, automation permission, timeouts, and window query failures. If the tab is missing, return to the identified originating app.
- Show macOS notification permission and suppress old archive alerts and resolved requests.
- Korean and English demos, installation steps, and update instructions.
