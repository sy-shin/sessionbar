# sessionbar 변경 기록 / Changelog

## 0.2.0-beta.5

### 한국어

- 종료 버튼을 **세션 종료…**로 바꾸고 확인창에 프로젝트와 요청을 함께 표시합니다.
- 일반 CLI 세션으로 확인한 경우에만 종료합니다. 공유 앱 서버·원격 연결·실행 방식이 불명확한 대상은 종료하지 않습니다.
- 종료 직전에 실행 방식과 프로세스 신원을 다시 확인합니다.

### English

- Renamed the action to **End session…** and show the project and request in the confirmation dialog.
- End only identified, independent CLI sessions. Shared app servers, remote connections, and unidentified execution modes are excluded.
- Recheck the execution mode and process identity immediately before ending the session.

## 0.2.0-beta.3

### 한국어

- 개인·회사 내부 사용, 수정, 무료 재배포를 허용하는 이용 조건을 추가했습니다.
- 앱·수정본 유료 판매, 유료 제품에 포함, 앱 기능의 유료 서비스 제공에는 사전 서면 허락이 필요합니다.
- 앱 번들·DMG·릴리스 첨부에 한국어·영어 이용 조건 전문을 포함합니다.

### English

- Added usage terms permitting personal and internal business use, modification, and free redistribution.
- Selling the app or modifications, including them in paid products, or offering their functionality as paid services requires prior written permission.
- Included the full license, with Korean translation, in the app bundle, DMG, and release attachments.

## 0.2.0-beta.2

### 한국어

- Apple Silicon·Intel용 Universal 앱을 DMG·ZIP으로 배포합니다.
- 미확인 목록에서 승인·입력 요청, 아직 읽지 않은 완료 결과, 확인하지 않은 오류를 관리합니다.
- 목록·상세 화면에서 작업 창으로 이동하고 선택한 Codex를 종료할 수 있습니다.
- 터미널 탭 없음·자동화 권한·응답 지연·창 조회 실패를 구분합니다. 탭을 찾지 못하면 확인된 출처 앱으로 이동합니다.
- macOS 알림 권한을 표시하고, 오래된 기록의 알림과 해결된 요청의 반복 알림을 억제합니다.
- 한국어·영어 사용 영상과 설치·업데이트 안내를 제공합니다.

### English

- Universal app for Apple Silicon and Intel Macs, packaged as DMG and ZIP.
- Review approval/input requests, unread completed results, and unreviewed errors.
- Return to task windows and quit the selected Codex from the list or detail view.
- Distinguish missing tabs, automation permission, timeouts, and window query failures. If the tab is missing, return to the identified originating app.
- Show macOS notification permission and suppress old archive alerts and resolved requests.
- Korean and English demos, installation steps, and update instructions.
