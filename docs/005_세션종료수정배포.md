# sessionbar 0.2.0-beta.4

## 한국어

- 종료 버튼은 **세션 종료…**로 표시하며 프로젝트와 요청을 확인한 뒤 실행합니다.
- 선택한 독립 CLI 세션만 종료하고 대화 기록은 유지합니다.
- 공유 앱 서버와 원격 연결, 실행 방식을 확인할 수 없는 대상에는 종료 신호를 보내지 않습니다. Codex 앱·IDE 내부 세션의 개별 종료는 이 버전에서 지원하지 않습니다.

macOS 14 이상 · Apple Silicon 및 Intel Mac용 Universal 앱입니다. DMG 또는 ZIP을 다운로드하고 `SHA256SUMS.txt`로 파일을 확인하세요.

개인·회사 내부 사용은 무료로 허용되며 유료 판매·유료 제품에 포함·앱 기능의 유료 서비스 제공에는 사전 서면 허락이 필요합니다. 전문은 첨부된 `LICENSE`와 앱 번들에 포함되어 있습니다.

Developer ID 서명·Apple 공증을 받지 않은 시험 배포입니다. [설치 및 업데이트 안내](https://github.com/sy-shin/sessionbar/blob/main/docs/000_%EC%84%A4%EC%B9%98%EB%B0%8F%EC%97%85%EB%8D%B0%EC%9D%B4%ED%8A%B8.md)를 확인하세요.

## English

- The action is labeled **End session…**. Check the project and request before confirming.
- End only the selected independent CLI session and keep its conversation history.
- Do not send termination signals to shared app servers, remote connections, or unidentified execution modes. Ending individual sessions inside the Codex app or IDE is not supported in this version.

Universal app for Apple Silicon and Intel Macs running macOS 14 or later. Download a DMG or ZIP and verify it with `SHA256SUMS.txt`.

Personal and internal business use are allowed without a license fee. Selling the app, including it in paid products, or offering its functionality as paid services requires prior written permission. The attached `LICENSE` and app bundle include the full terms.

This beta has no Developer ID signature or Apple notarization. Read the [installation and update guide](https://github.com/sy-shin/sessionbar/blob/main/docs/000_%EC%84%A4%EC%B9%98%EB%B0%8F%EC%97%85%EB%8D%B0%EC%9D%B4%ED%8A%B8.md).
