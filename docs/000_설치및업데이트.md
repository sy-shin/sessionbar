# sessionbar 설치 및 업데이트 / Install and update

## 한국어

### 다운로드 및 설치

- macOS 14 이상에서 사용할 수 있습니다. Universal 앱은 Apple Silicon과 Intel Mac을 모두 지원합니다.
- [GitHub Releases](https://github.com/sy-shin/sessionbar/releases)에서 버전을 선택합니다.
- DMG를 열고 `sessionbar.app`을 `Applications`로 드래그합니다. ZIP을 선택했다면 압축을 풀고 앱을 응용 프로그램 폴더로 옮깁니다.
- 앱을 열고 메뉴 막대의 sessionbar 아이콘을 누릅니다. 소스 빌드 도구는 필요하지 않습니다.

### 이용 조건

개인·회사 내부 사용은 무료로 허용됩니다. 앱·수정본 유료 판매, 유료 제품에 포함, 앱 기능의 유료 서비스 제공에는 사전 서면 허락이 필요합니다. [이용 조건](https://github.com/sy-shin/sessionbar/blob/main/LICENSE)을 확인하세요. 앱 안의 `Contents/Resources/LICENSE`에도 전문이 포함되어 있습니다.

### 처음 열 때

이 시험 배포는 Developer ID 서명·Apple 공증을 받지 않았습니다. macOS가 실행을 차단할 수 있습니다. 다운로드 출처와 아래 SHA-256을 확인하고, 직접 실행하기로 결정한 경우 Apple의 [앱 열기 안내](https://support.apple.com/102445)를 따르세요. macOS 보안 설정을 전체 해제하는 명령은 필요하지 않습니다.

### 권한

| 기능 | 필요한 권한 |
|:--|:--|
| 알림 | macOS 알림 허용 |
| Terminal·iTerm2 창·탭 이동 | 해당 터미널 앱 자동화 허용 |
| 다른 앱의 프로젝트 창 이동 | sessionbar 접근성 허용 |
| 추가 폴더의 세션 기록 읽기 | 앱에서 선택한 세션 폴더 접근 |
| 선택한 Codex 종료 | 추가 권한 없음 |

권한이 없으면 해당 기능에서 설정을 열 수 있습니다. 프로젝트 폴더 열기·재개 명령 복사도 사용할 수 있습니다.

### 업데이트

1. sessionbar 메뉴의 종료를 누릅니다. Codex 세션은 계속 실행됩니다.
2. Releases에서 새 버전을 받아 기존 앱을 교체하고 다시 엽니다.
3. 설정과 확인 표시는 유지됩니다.
4. 시험 배포 앱을 교체한 뒤 창 이동 권한이 인식되지 않으면 **시스템 설정 → 개인정보 보호 및 보안 → 접근성**에서 기존 sessionbar 등록을 제거하고 현재 설치된 앱을 다시 추가합니다.

자동 업데이트는 제공하지 않습니다. 새 버전은 Releases에서 확인하세요.

### 파일 확인

다운로드한 파일이 있는 폴더에서 다음 명령을 실행하고 Releases의 `SHA256SUMS.txt`와 비교합니다.

```sh
shasum -a 256 sessionbar-0.2.0-beta.4-macos-universal.dmg
```

## English

### Download and install

- Requires macOS 14 or later. The Universal app supports both Apple Silicon and Intel Macs.
- Choose a version in [GitHub Releases](https://github.com/sy-shin/sessionbar/releases).
- Open the DMG and drag `sessionbar.app` to `Applications`. For the ZIP, extract it and move the app to Applications.
- Open the app and select its menu bar icon. No compiler or source build tools are required.

### First launch

This beta has no Developer ID signature or Apple notarization. macOS may block it. Verify the download source and SHA-256 below. If you decide to run it, follow Apple's [instructions for opening apps](https://support.apple.com/102445). You do not need to disable macOS security globally.

### Permissions

| Feature | Permission |
|:--|:--|
| Notifications | macOS notification permission |
| Terminal / iTerm2 window and tab navigation | Automation permission for that terminal |
| Selecting a project window in another app | Accessibility permission for sessionbar |
| Reading records in additional folders | Access to the session folder selected in the app |
| Quitting the selected Codex | No additional permission |

The relevant feature can open its settings. You can also open the project folder or copy the resume command.

### Updating

1. Quit sessionbar from its menu. Your Codex sessions keep running.
2. Download the new version from Releases, replace the existing app, and reopen it.
3. Settings and review markers remain available.
4. If a beta replacement loses window navigation permission, remove the old sessionbar entry under **System Settings → Privacy & Security → Accessibility** and add the currently installed app again.

There is no automatic updater. Check Releases for new versions.

### Verify the download

Run the following in your download folder and compare it with the release's `SHA256SUMS.txt`:

```sh
shasum -a 256 sessionbar-0.2.0-beta.4-macos-universal.dmg
```
