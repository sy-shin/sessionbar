# sessionbar 0.2.0-beta.1

## 한국어

macOS 14 이상에서 Apple Silicon·Intel Mac용 앱을 바로 설치할 수 있습니다.

- **DMG**: 앱을 Applications로 드래그해 설치합니다.
- **ZIP**: 압축을 풀고 앱을 응용 프로그램 폴더로 옮깁니다.
- **SHA256SUMS.txt**: 다운로드 파일의 SHA-256을 확인합니다.
- **한국어·영어 MP4**: 예시 데이터로 세션 목록·미확인 결과·상세 응답·확인 처리·작업 창 이동 버튼을 보여줍니다.

여러 Codex CLI 세션의 상태와 미확인 결과를 모아 보고, 해당 작업으로 돌아가거나 선택한 Codex를 종료할 수 있습니다.

이 버전은 **시험 배포**이며 Developer ID 서명·Apple 공증을 받지 않았습니다. macOS가 실행을 차단할 수 있으므로 [설치 및 업데이트 안내](https://github.com/sy-shin/sessionbar/blob/main/docs/000_%EC%84%A4%EC%B9%98%EB%B0%8F%EC%97%85%EB%8D%B0%EC%9D%B4%ED%8A%B8.md)를 확인하세요.

실행·승인·유휴 상태는 추정으로 표시됩니다. VS Code 프로젝트 창 이동을 확인했으며 Terminal·iTerm2 탭 및 tmux pane 이동은 각 환경의 연결 정보와 권한에 따라 달라집니다. 이번 배포에서는 자동화 오류 분류·복구 경로와 스크립트 컴파일을 검증했으며 모든 실제 터미널 환경을 검증한 것은 아닙니다.

## English

Install the Universal app on Apple Silicon or Intel Macs running macOS 14 or later.

- **DMG**: drag the app to Applications.
- **ZIP**: extract the app and move it to Applications.
- **SHA256SUMS.txt**: verify your download's SHA-256.
- **Korean / English MP4**: synthetic examples of the session list, unreviewed results, detail reply, review action, and return button.

Track multiple Codex CLI sessions and unread results, return to your work, and quit the selected Codex.

This is a **beta**, without a Developer ID signature or Apple notarization. macOS may block it. Read the [installation and update guide](https://github.com/sy-shin/sessionbar/blob/main/docs/000_%EC%84%A4%EC%B9%98%EB%B0%8F%EC%97%85%EB%8D%B0%EC%9D%B4%ED%8A%B8.md).

Running, attention, and idle states are estimates. VS Code project window navigation has been checked. Terminal/iTerm2 tabs and tmux panes depend on connection metadata and permissions. Error classification, recovery paths, and script compilation are checked; every real terminal configuration has not been verified.
